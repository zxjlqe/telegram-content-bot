# بوت أقسام وملفات تيليجرام

بوت مستقل ببايثون + SQLite، بدون صانع بوتات.

## المزايا
- أقسام وأقسام فرعية.
- إضافة المحتوى من داخل البوت.
- ملفات وصور وفيديو وصوت ونصوص.
- لوحة تحكم خاصة بالمدير.
- إحصائيات.
- إدارة الأقسام.
- حذف المحتوى.
- إذاعة للمستخدمين.
- حفظ البيانات في SQLite.

## التشغيل على Termux

```bash
pkg update
pkg install python -y
pip install -r requirements.txt
```

ثم ضع التوكن ومعرف المدير:

```bash
export BOT_TOKEN="توكن_البوت"
export ADMIN_IDS="معرفك_في_تيليجرام"
python bot.py
```

للحصول على التوكن استخدم @BotFather.
معرف المدير هو رقم Telegram ID الخاص بك.

## ملاحظة
هذا إصدار أساسي قوي كبداية. يمكن إضافة صلاحيات متعددة للمديرين، بحث حقيقي، ترتيب الأقسام بالسحب/الأزرار، إحصائيات استخدام، نسخ احتياطي، حماية من السبام، وإدارة متقدمة للمحتوى.
